Formora Privacy Policy

Effective September 25, 2026. Publisher: Shrey Omer. Contact: shreyomer10@gmail.com.

Formora fills job applications from information you provide and lets you review the results. It never submits an application for you. This policy covers the Formora Chrome extension.

Information stored on your device

The extension stores your Gemini API key, settings, profile (including any contact, employment, education, salary or other facts you enter), resume file and text, remembered answers, setup progress and aggregate API token counts in Chrome extension local storage. This storage is not encrypted by Formora or synced by Formora to another device. Panel position, size and application-step state use the current site's tab session storage.

Reading and filling pages

Content scripts run on supported web pages to provide the panel and detect form changes. When you request a scan or fill, Formora reads form questions, choices, existing values and page context. A scan processes this locally. Filling writes answers and may attach your stored resume to the application site's upload controls. The site can receive data as you type or autofill, before you submit; its own policy applies. Google Forms uploads can use Google's Drive picker.

Google Gemini

When you choose AI resume extraction, your resume document is sent directly to Google's Gemini API. When unanswered questions need AI, Formora sends your profile, resume text, custom instructions, relevant previous answers, form questions and page context (which can include the page URL and text) to Google. Key and model tests send small test prompts. Requests use HTTPS and your API key; fallback models use the same provider.

Formora requests store: false, which disables interaction storage for later retrieval. This does not override Google's separate data handling, safety logging or retention terms. Unpaid Gemini services may use inputs and outputs for product improvement and human review; Google's terms say not to send personal, sensitive or confidential information to unpaid services. Use a suitable paid project for personal resume data. Paid-service processing and retention remain governed by Google's Gemini API terms and Google's privacy policy.

Diagnostics and support

Formora keeps a bounded extraction log in memory for the current page run. Copy diagnostic writes a report to your clipboard, or shows selectable text if copying fails. Reports contain the site origin, extension version, viewport, extraction log, field labels, result states and panel notes. Answer values and resume contents are not deliberately included. The report filters known profile strings and common email, key, URL and phone patterns, but labels and notes can still contain personal information. Review and edit the report before sharing it.

No report is sent automatically. If you email a report or support request to the publisher, the publisher receives what you send and uses it to respond and troubleshoot. You can request deletion of that correspondence at the contact address above.

Sharing and permissions

Formora has no publisher-operated data backend, advertising or analytics service. The extension does not sell user data or transfer it for advertising. Google processes the API requests described above, and application sites receive the data you choose to fill or upload. Storage saves your setup; activeTab and scripting let the extension run its controls on the chosen page; the Google API host permission allows AI requests. The sidePanel permission hosts the review UI in the browser's own panel. Its temporary connection to the active tab carries the displayed fields, answers and explicit review actions within the extension; it is not an external upload. Content scripts across web pages support different application sites and embedded upload frames.

Your choices and deletion

Edit your profile and key in Settings and save, or clear remembered answers there. Uninstalling Formora removes its Chrome extension local storage; closing the site tab clears that tab's session state and in-memory diagnostics. Copies you put on the clipboard, send by email, submit to sites or send to Google are governed by those systems and are not removed by uninstalling. Contact the publisher about support correspondence; contact the receiving site or Google about their copies.

Changes

This policy will be updated when data handling changes. The effective date above identifies the current version. Direct privacy questions to shreyomer10@gmail.com.
